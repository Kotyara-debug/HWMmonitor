# HWMmonitor
A handy utility for monitoring temperature, load, fan speeds, and GPU and CPU core frequencies.
Удобная утилита для мониторинга температуры, нагрузки, скорости вентиляторов, а также частоты ГПУ, ЦПУ
first open exe file, then open monitoring menu press "-"
сначала откройте ехе файл, затем для открытия меню мониторинга нажмите минус
